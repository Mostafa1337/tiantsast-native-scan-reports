# TAINTSAST Native Scan Reports

Security scan reports generated by **TAINTSAST**, a private static application security testing (SAST) tool for native applications.

## Reports

| Report | Description |
| ------ | ----------- |
| `InsecureBankv2.html` | SAST scan results for the InsecureBank v2 Android application |
| `insecureshop.html` | SAST scan results for the InsecureShop application |
| `OVAA.html` | SAST scan results for the OVAA (Oversecured Vulnerable Android App) |

## How to View a Report

1. Download the HTML report file you want to inspect.
2. Open the downloaded file in any web browser (Chrome, Firefox, Edge, etc.).
3. The report renders in your browser.

## Notes

- The reports are static HTML snapshots generated by the TAINTSAST scanner.
- Each report contains the detected taint-analysis findings, vulnerability details, and source-to-sink traces.
